Always current

Auto updates, without the wait

The launcher checks for new builds in the background and applies patches incrementally, so most updates finish before you've finished reading the changelog.

  • Delta patching keeps downloads small
  • Updates apply while you browse cosmetics or news
  • Roll back to the previous build in one click if something looks off
Integrity, checked

File verification you never have to think about

Every install is checksummed against the source build. If a file's missing or corrupted, the launcher repairs just that file — not a full reinstall.

  • Per-file checksum verification on every launch
  • Targeted repair instead of full redownloads
  • A visible status log if you want to see what changed
Sign in once

Discord login, carried everywhere

Connect your Discord account once and the launcher, client and community site all recognize you — no separate passwords to manage.

  • OAuth sign-in, no new password to remember
  • Friends list synced from your Discord servers
  • Session stays active across launcher restarts
Built for speed

Fast downloads, wherever you are

Content is served from a distributed edge network, so first installs and season updates move at your connection's real speed.

  • Edge-cached delivery in 120+ regions
  • Automatic mirror selection, no manual server picking
  • Pause and resume without losing progress
